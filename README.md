# Temple of Nihility

虚无圣殿 — Minecraft 26.2 / NeoForge 26.2.0.7-beta 内容扩展模组。

> **开发中测试版 / In-development beta**
>
> 当前发布仅用于测试 NeoForge 26.2 版本的玩法、界面、贴图和多方块结构。内容、数值、合成、结构、存档数据与 API 联动仍可能调整，不建议直接用于长期主存档。

当前仓库只保留正在维护的有效版本：NeoForge 26.2。旧版迁移备份、生成预览、本地测试输出和私有贴图生成脚本不会进入仓库。

## 功能

| 内容 | 说明 |
|------|------|
| 虚无圣典 | 使用原版书本界面的游戏内指南，介绍圣殿、祭坛图、生物、宝库、能量和游玩流程 |
| 四系材料 | 虚无残片、归尘、空相结晶、圣殿符文、虚无核心、混沌共鸣核 |
| 圣殿建筑 | 空寂石系方块、圣殿符文砖、虚空灯、虚空玻璃、归零祭坛 |
| 武器工具 | 匕首“缺位步”、剑“归零斩”、巨刃“断界式”，以及镐、斧、铲、锄 |
| 装备 | 虚无头盔、胸甲、护腿、靴子 |
| 饰品 | Curios 必需依赖：戒指、项链、腰带、披风、手甲、时沙计、魂锚等 |
| 虚无宝库 | 多方块仓储网络，每个宝库 243 格；同一所有者的相邻宝库自动合并，并带访问保护 |
| 虚无终端 | 可放入 Curios 常见饰品栏，默认 `O` 打开绑定的宝库网络 |
| 常加载 | 使用 NeoForge 独立票据，在终端中切换；默认每个网络最多常加载 9 个区块 |
| 归零祭坛 | 多方块仪式核心，按结构等级把现有材料进阶为结晶、符文、封印和核心 |
| JEI 联动 | 终端界面支持 JEI 物品拖入搜索框、终端物品可被 JEI 点击识别 |
| 主动道具 | 灯核、复苏宝珠、遁影符、净化铃、洞察镜、屏障核、相位羽、引力符、战号 |
| 虚无状态 | 自定义“遁入虚无 / 融于虚无 / 隐入虚无”，不再使用原版隐身充当效果 |
| 交易提示 | 深渊生物交易会明确提示材料不足、冷却和获得物品 |

## 玩家入口

- 一本书加空寂石、虚无残片或归尘任一种即可合成《虚无圣典》；右键打开完整游戏内指南。
- 默认按 `O` 打开携带或佩戴的已绑定虚空终端；按键会通过模组网络包请求服务端打开，不依赖聊天指令。
- 正常玩法不需要聊天命令：物品、方块、GUI 和按键都通过服务端动作 API、NeoForge 事件和自定义网络包执行；`/temple` 仅保留给管理员调试生成结构。
- 归墟匕首右键：施展缺位步；归零之刃按住右键蓄力后松开：释放归零斩；断界巨刃右键：施展三段断界式。
- 拿着虚空终端潜行右键虚空宝库：绑定终端。
- 打开虚空宝库或虚空终端后，在终端界面点击“加载开/加载关”切换整个宝库网络常加载；关闭前会弹出确认。
- 右键归零祭坛：打开仪式界面。祭坛周围四向放 `圣殿符文砖` 为 I 级，四角加 `虚空水晶块` 为 II 级，两格外四向加 `圣殿柱` 且外四角加 `錾制空寂石` 为 III 级。
- 祭坛仪式：放入材料后点击“仪式”。当前支持粉尘→碎片、碎片→结晶、结晶→符文、符文→封印、封印→核心、核心→共鸣核心等进阶。

## 构建

需要 JDK 25。NeoForge 26.2 文档要求 Java 25，本项目使用 ModDevGradle。

```powershell
.\gradlew.bat build
```

构建产物：

```text
build/libs/temple-of-nihility-neoforge-26.2-1.0.0-beta.3.jar
```

## 依赖与联动

- 必需：Curios `15.0.0-beta.1+26.2`
- 可选：JEI `30.7.0.40` for NeoForge 26.2
- 可选：Waystones `26.2.0.3` for NeoForge 26.2

JEI、Waystones 与 Balm/Shogi 使用公开 Maven 坐标。Curios 26.2 API 尚无公开构建坐标，编译期使用已核对兼容的 26.1 API；实际运行仍要求安装 Curios `15.0.0-beta.1+26.2`。

## 开发约定

- 不把构建产物、测试运行目录、备份目录、生成预览图提交到仓库。
- 不提交本地 API Key、provider 配置、AI 生成原始响应。
- 世界生成结构已启用测试；修改结构/矿脉/放置规则后必须进世界看日志，确认没有 `RegistryDataLoader` 或 worldgen Codec 报错。
