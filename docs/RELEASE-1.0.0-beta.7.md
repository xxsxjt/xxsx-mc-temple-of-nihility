# Temple of Nihility 1.0.0-beta.7

## 核心改动 / Highlights
- **归零之刃 · 真实飞行剑气与真斩杀（Blade of Zero）**：
  - 将「归零斩」从原本的瞬发眼高射线重构为 **10 tick 向前飞行的三维新月剑气**（从贴脸 `-0.65` 格一直向前推进至 `10 / 13 / 16` 格），近身与远距离目标均可稳定命中，沿途同步斩断敌对投射物。
  - 实装完整的**穿甲真实斩杀**：目标拥有 3 层存在削减或生命 ≤ 35% 时触发无视护甲的真实斩杀追加伤害、剥离增益、返还 12 点虚无能量与专属斩杀粒子爆发；非 Boss 目标在命中后残血 ≤ 25%（或 3 层存在削减下 ≤ 35%）将直接触发**必死终结斩杀**。
- **断界巨刃 · 三段界裂全部命中（Boundary Greatsword）**：
  - 修复三段攻击共享同一个命中集合且间隔落入原版无敌帧导致仅有第一段生效的问题。
  - 重构为每段独立判定 + 每段独立清除无敌帧 + `{15, 21, 27}` tick 三连节奏（同步第一/第三人称动作），贴身范围（`-0.65` 格起）三段全部可稳定命中，伤害逐段递进（`0.90×+2` → `1.10×+4` → `1.45×+7`），且第一段破甲后第二、三段自动吃到 `+35%` 增伤。
- **圣殿五阶生物战斗强度全面增强（Temple Creatures）**：
  - 全面上调 T1–T5 生命值、攻击力、护甲、韧性、移速与击退抗性：信众 `44 HP / 6 ATK`、随行者 `76 HP / 9 ATK`、令使 `128 HP / 13.5 ATK`、大令使 `220 HP / 18.5 ATK`、虚无圣者 `420 HP / 26 ATK / 20 护甲 / 10 韧性`。
  - 同步提高虚无圣者抹除直线（`20.0`）、缺失区（`7.0`）与归零终式（`10.0`）的技能压迫感，加快近战追击速度。
- **虚无契约交易界面重制（Void Obsidian Trade GUI）**：
  - 绘制全新暗色黑曜石风格 `nihility_trade.png`（与虚空终端视觉语言统一），彻底消除原版村民贴图导致的标题/层级/按钮/物品栏文字重叠，居中对齐三槽位与自定义青色滚动条、箭头。
  - 选中契约时自动从玩家背包抓取匹配货币投入支付槽，并自动退回不匹配的旧货币，交易体验丝滑。
- **虚空宝库原生自动化与跨模组兼容（AE2 / Refined Storage / Easy Autocrafting）**：
  - 为 `templenihility:nihility_vault` 注册 NeoForge 事务级 `Capabilities.Item.BLOCK`（`ResourceHandler<ItemResource>`），以整个相连的同主虚空宝库网络作为统一存储后端，完整支持模拟与事务回滚。
  - 原生兼容 **AE2 存储总线（Storage Bus）**、**精致存储外部存储（External Storage）**、各类漏斗/管道以及配套新模组 **更简易的自动合成（Easy Autocrafting）**。
