## 当前允许保留的原版效果

- 夜视：虚空适应项链、虚无蚀月坠和回响镜的观察辅助，提示中明确写出。
- 发光：回响镜、星界罗盘、哨戒眼和信标的可视辅助；伤害加成由模组自己的标记状态处理。
- 虚弱：净业铃和引力场的次要压制；震退、持续牵引和状态拒绝等核心行为由模组代码处理。
- 三个虚无状态使用本模组 `MobEffect` 作为可见状态载体，但飞行、穿墙、隐身、目标取消、伤害规则和恢复都由 `VoidPhaseEvents` 实现，不调用原版指令。

## 发布前运行时复测重点

1. 遁入/融于虚无结束后，生存、创造、旁观和其他模组授予的飞行权限都正确恢复。
2. 缺位步穿过墙和实体但不会落入实体方块、世界边界或未加载区块。
3. 屏障、套装闪避、相位免伤、魂盾和 Curios 减伤叠加时只消耗实际生效的资源。
4. 停滞不会永久冻结实体，魂锚与王冠不会重复触发，时沙计不会因多栏位重复加速。
5. 自定义粒子资源在客户端无缺图、黑边或粒子 JSON 报错。
