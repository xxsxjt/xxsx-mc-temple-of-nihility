# Temple of Nihility 1.0.0-beta.6

## 主要改动

1. **修复虚无战斧第一/第三人称动作**：
   - 修复 `NihilityWeaponAnimation` 中战斧普攻未应用挥砍变换导致的手持僵直问题，新增战斧左键交替重劈/回勾挥砍动作。
   - 新增战斧右键「破界重劈」专属第一/第三人称蓄力下劈演出，并同步接入新低/中阶剑斧动作。
2. **新增低阶与中阶递进装备 + 重构高阶获取难度**：
   - 新增低阶「空寂/归尘阶」7 件装备（归尘剑/斧/镐 + 空寂护甲 4 件套）与中阶「裂隙/虚影阶」7 件装备（裂隙战刃/战斧/镐 + 虚影护甲 4 件套），配备独立 32×32 图标、护甲模型贴图与主动技（裂隙斩 / 裂隙破甲）。
   - 支持三阶护甲跨阶混穿继承套装效果，平滑过渡不掉套装收益。
   - 修复归零之刃与归墟匕首原有 3×3 合成配方冲突，重构所有终局武器/工具/护甲配方，要求中阶装备进阶并消耗圣殿封印、虚无核心、圣殿遗物残片、共鸣核心与下界合金（全模组 87 个有序配方零冲突）。
3. **虚空宝库终端 GUI 全面重绘与渲染验收**：
   - 重绘 256×256 深色虚空黑曜石 + 青色晶脉终端底图，彻底清除旧底图左下角灰色缺块与错位槽框。
   - 修复 `void_shards.png` 贴图宽度常量错误导致的 2× 横向压缩，重绘 128×64 悬浮虚空晶簇。
   - 优化右侧控件区与 3×3 合成区排布，顶部预留第三方整理模组安全区，新增暗色半透明空宝库提示卡与对齐滚动条。
